تعديل الموقع من الداخل

من هنا تعدّل الكتب والشهادات والمهارات والخبرات والمسار وكل نص في الموقع، دون لمس الكود. الحفظ يتم مباشرة في مستودعك على GitHub، ولا يستطيع أحد غيرك الحفظ لأن الحفظ يحتاج رمزك الخاص.

كيف أنشئ الرمز؟ (مرة واحدة فقط)
  1. افتح github.com/settings/personal-access-tokens/new وأنت مسجّل الدخول.
  2. في Token name اكتب site-admin، وفي Expiration اختر مدة (سنة مثلاً).
  3. في Repository access اختر Only select repositories ثم اختر eng-youssefamir.github.io فقط.
  4. افتح Permissions ثم Repository permissions، وغيّر Contents إلى Read and write.
  5. اضغط Generate token وانسخ الرمز الذي يبدأ بـ github_pat_. يظهر مرة واحدة فقط.
  6. الصقه في الخانة أعلاه واضغط دخول.

هذا الرمز يعمل على مستودع الموقع فقط، ولا يستطيع فعل شيء آخر في حسابك. لا تشاركه مع أحد. إن ضاع أو شككت فيه فاحذفه من GitHub (Revoke) وأنشئ غيره. وفعّل التحقق بخطوتين على حسابك، فهو القفل الحقيقي لموقعك.

لا توجد تغييرات.
